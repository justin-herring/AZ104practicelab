Entra ID Groups

Security groups and Microsoft 365 groups for RBAC and collaboration
Best Practice: Assign Azure RBAC roles to groups instead of individual users. When someone joins or leaves a team, update group membership — no need to touch role assignments. This simplifies auditing and reduces misconfiguration risk.
Create Group
Group Types Explained
Security Group: Used for RBAC, app access, Conditional Access. Can be assigned Azure roles.
Microsoft 365 Group: Includes shared mailbox, calendar, Teams. For collaboration. Can be role-assignable (newer feature).
Dynamic Membership: Members auto-added based on user attributes (not simulated here but key for exam).
Nested Groups: Supported in Entra ID — roles assigned to a parent group apply to members of child groups.
