Activity Log

Azure Monitor Activity Log — records all subscription-level management operations
The Azure Activity Log (equivalent to AWS CloudTrail) records every management operation: who performed it, when, what resource was affected, and whether it succeeded or failed. Critical for security audits, incident response, and compliance. Retention: 90 days by default — export to Log Analytics or Storage for longer retention.

KQL Queries for Log Analytics (AZ-104 Exam)

In real Azure, you'd query the Activity Log with KQL in Log Analytics:

// Failed operations in last 24 hours AzureActivity | where ActivityStatusValue == "Failed" | where TimeGenerated > ago(24h) | project TimeGenerated, Caller, OperationNameValue, ResourceGroup | order by TimeGenerated desc
// RBAC role assignment changes AzureActivity | where OperationNameValue contains "roleAssignments" | project TimeGenerated, Caller, OperationNameValue, Properties | order by TimeGenerated desc
Exam tip: KQL (Kusto Query Language) is used in Log Analytics, Azure Monitor, and Microsoft Sentinel. Key operators: where, project, summarize, order by, ago().
