Azure RBAC Evaluation Rules
Additive model: Access = union of all applicable role assignments. More role assignments = more access.
Scope inheritance: Assignments at broader scopes apply to all child scopes (MG → Sub → RG → Resource).
Default deny: No explicit allow = access denied. Azure denies everything by default.
NotActions ≠ Deny: NotActions only removes from that role's permissions. Another role can still grant the action.
